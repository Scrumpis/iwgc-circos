The OFL also restricts selling the font by itself, reserved-name use for modified
fonts, and implied endorsement. We do not modify or rename this font.
See the [official license](https://openfontlicense.org/open-font-license-official-text/).

Ordinary figure artwork does not become OFL licensed just because it uses the
font. The legend embeds the selected font in SVG; keep this notice available
when distributing font assets. See the [OFL FAQ](https://openfontlicense.org/ofl-faq/).

The historical Arial binary is removed from the 0.4.0 candidate. Existing Git
history and historical figure files are preserved; the old SVG can refer to
Arial by name/path, but contains no embedded Arial binary. Build/publish from
the frozen candidate commit, rather than archiving an older tag.
